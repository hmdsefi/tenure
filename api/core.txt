package core // import "github.com/hmdsefi/tenure/core"

Package core holds every decision tenure makes as pure, deterministic code: key
hashing, assignment, ranking, the ownership machine, timing and partition trees.

VARIABLES

	ErrInvalidTiming = errors.New("core: invalid timing")

FUNCTIONS

func Balanced(space string, n int, keys []string) []int
    Balanced assigns the n shards of space to placement keys and returns, for
    each shard 0…n-1, the index in keys of its key; every entry is -1 when keys
    is empty. Every key gets ⌊n/m⌋ or ⌈n/m⌉ shards for m keys, and the result
    depends only on space, n and the set of keys: reordering keys only relabels
    the indices.

    Each (shard, key) pair is scored with Score(space, strconv.Itoa(shard),
    key). Pairs are taken greedily by descending score (ties: key ascending,
    then shard ascending) when the shard is still unassigned and the key is
    under its cap: ⌈n/m⌉ while fewer than n mod m keys have reached ⌈n/m⌉,
    and ⌊n/m⌋ after that.

    Balanced takes time O(n·m·log(n·m)) and memory O(n·m); compute it once per
    view change, not per lookup. It does not modify keys. Balanced panics if n <
    1 or keys contains a duplicate.

func KeyShard(key string, n int) int
    KeyShard returns the shard in 0…n-1 that key belongs to: the 64-bit FNV-1a
    hash of key, passed through MurmurHash3's 64-bit finalizer, modulo n.
    Doubling n splits shard s into s and s+n. KeyShard panics if n < 1.

func PlacementKeys(v View, at time.Time, expired []bool) (keys []string, slots []int)
    PlacementKeys returns the placement keys Balanced takes for the view v and,
    in a view with slots, the slot each key names.

    Without slots, keys are the IDs of Eligible(v, at) in ID order and slots
    is nil. With slots, keys are "slot-0" … "slot-<k-1>" in slot order,
    including vacant slots and slots whose holder is draining, except vacant
    slots whose entry in expired is true; slots[i] is the slot keys[i] names.
    expired is the caller's observation of which slots have been vacant for at
    least Timing.SlotGrace; nil means none. at is used only without slots.

    PlacementKeys panics if expired is not nil and its length differs from
    v.Slots, or if len(v.SlotHolders) differs from v.Slots.

func Score(namespace, key, memberID string) uint64
    Score returns the rendezvous score of memberID for key in namespace:
    MurmurHash3's 64-bit finalizer applied to the 64-bit FNV-1a hash of
    namespace, a zero byte, key, a zero byte and memberID. It is the score
    lockstep's virtual actors use, with namespace as the actor kind. Score does
    not allocate.

type ClaimSlot struct{}

type CloseSession struct{}
    CloseSession asks the driver to close the session. Every run has returned by
    then. The driver answers it with SessionClosed once the session is closed.

type Confirm struct {
	// Space and Shard name the shard.
	Space string
	Shard int

	// Term is the term of the run.
	Term Term
}
    Confirm asks the driver to read a shard's record back, so that a degraded
    run can be restored. The answer is a HolderChanged input.

    A Confirm carries no ID. Once one is out, and for as long as the session
    stays live, any record that names this holder in the run's term restores the
    run, and the machine cannot tell the answer from a reading taken earlier,
    before another holder took the shard. So while Status shows the shard
    degraded, the driver must step such a record only when its read started
    after the shard's latest Confirm, and hold back any other.

type Degrade struct {
	// Space and Shard name the shard.
	Space string
	Shard int

	// Term is the term of the run.
	Term Term
}
    Degrade tells the driver that a run in a fenced space has lost its live
    session. The run keeps going.

type KeepAlive struct{}

type Machine struct {
	// Has unexported fields.
}
    Machine is the ownership state machine of one member. It reads no clock,
    starts nothing and performs no I/O: the driver feeds it inputs through Step
    and carries out the actions Step returns.

    A Machine is not safe for concurrent use.

func NewMachine(cfg MachineConfig) *Machine
    NewMachine returns a Machine for cfg, with its spaces sorted by name,
    its session opening, no slot, every shard idle and no timer armed. It panics
    with the error of cfg.Validate when cfg is not valid. It copies cfg.Spaces
    and does not modify it.

func (m *Machine) Assignment(space string) []string
    Assignment returns the placement key of each shard of the named space,
    indexed by shard number, or nil when the machine has no such space. The key
    is "" for a shard with no key, so every key is "" before the first view.
    In a view with slots the keys are "slot-0", "slot-1" and so on. Callers
    must not modify the result. A new assignment is stored in a new slice,
    so an earlier result never changes.

func (m *Machine) NextWake() (time.Duration, bool)
    NextWake returns the reading of the earliest armed timer and true, or 0 and
    false when no timer is armed. A new Machine has no timer armed.

func (m *Machine) Status() Status
    Status returns a snapshot of the machine. The result shares no memory with
    the machine.

func (m *Machine) Step(in Input) []Action
    Step applies one input and returns the actions the driver must carry out,
    or nil when there are none. It panics when in is nil.

    The machine's clock moves to the input's Now and never back, so an input
    with an older Now runs at the machine's own reading. The clock stops 24
    hours short of the largest Duration, where the session is never live,
    so that every timer's reading fits. A value of any other type that satisfies
    Input, such as a pointer to an input, leaves the clock where it is. An input
    that does not apply, such as a renewal sent after the clock's reading or
    an answer to a request the machine did not make, has no effect of its own,
    but the rest of the step still runs, so whatever is due still happens.

    Actions come in a fixed order: ExtendDeadline and KeepAlive; then StopRun,
    Degrade and Restore; StartRun; Release, Confirm and Acquire; ReleaseSlot
    and ClaimSlot; CloseSession; and Wake last. When a timer is armed the
    result ends with a Wake for the reading NextWake returns, which is after the
    machine's clock, and contains no other Wake.

    The step that accepts a lost session returns a StopRun for each run not yet
    told to stop. Later steps return no action but a Wake, until every shard is
    idle and Status reports Done.

    After a Drain the machine wants no shard, so it stops every run and hands
    each shard over. Once every shard is idle, every run having returned,
    a stuck one included, it returns CloseSession, and again every RetryPeriod
    until a SessionClosed. While the session is closing, every input but a Tick
    and a SessionClosed is ignored, and a step returns nothing but CloseSession
    and Wake. A lost session is never closed.

    Once Status reports Done, Step returns nil. Once the session is closed,
    the clock stops too.

type MachineConfig struct {
	// Holder is the session holder string, the name a shard's record uses for this member's
	// session. It is non-empty.
	Holder string

	// Member is this member's ID, which is also its placement key in a view without slots.
	// It is non-empty and contains neither '/' nor a zero byte.
	Member string

	// Spaces lists the spaces the member takes part in, at least one.
	Spaces []SpaceSpec

	// Timing holds the session timings. The zero value means DefaultTiming.
	Timing Timing
}
    MachineConfig configures a Machine.

    Write MachineConfig values with keyed fields: later versions add fields.

func (c MachineConfig) Validate() error
    Validate reports whether c can configure a Machine: Holder is non-empty,
    Member is non-empty and contains neither '/' nor a zero byte, there is at
    least one space, every space has a non-empty, distinct Name and at least one
    shard, and Timing is valid. It checks in that order and returns the first
    failure, which wraps ErrInvalidMachineConfig. A failure of Timing is the
    error of Timing.Validate, unchanged, so it wraps ErrInvalidTiming instead.

type Member struct {
	// ID identifies the member across restarts, for example its pod name. It is non-empty
	// and contains neither '/' nor a zero byte.
	ID string

	// Addr is where callers reach the member, for example "10.0.0.7:8080". core does not
	// interpret it.
	Addr string

	// Meta holds string labels. core does not interpret or modify it; a Member copied by a
	// core function shares the map.
	Meta map[string]string

	// Draining reports that the member is handing its work over before it leaves.
	Draining bool

	// Slot is the slot the member holds in a view with slots, or -1 for none. In a view
	// without slots it has no meaning. The runtime sets it when it merges slot data into a
	// view.
	Slot int

	// JoinAt and LeaveAt bound, in wall-clock time, when the member takes part in
	// placement: from JoinAt, inclusive, to LeaveAt, exclusive. A zero time is no bound.
	JoinAt  time.Time
	LeaveAt time.Time
}
    Member is one process taking part in a group.

    Write Member values with keyed fields: later versions add fields.

func Eligible(v View, at time.Time) []Member
    Eligible returns the members of v that may be given shards or keys at the
    wall-clock time at: members that are not draining, whose [JoinAt, LeaveAt)
    window contains at (a zero bound is open), and that are not standbys
    (members without a slot in a view with slots). The result is a new slice in
    ID order, nil when no member is eligible.

func Rank(namespace, key string, members []Member, n int) []Member
    Rank returns the first n members of members for key in namespace,
    best first: by Score descending, then by ID ascending, then by position
    in members. It ranks every member it is given, whatever its other fields;
    callers filter first. The result is a new slice of min(n, len(members))
    copies, nil when n <= 0 or members is empty. Rank does not modify members.

func (m Member) Validate() error
    Validate reports whether m can take part in a group: ID is non-empty and
    contains neither '/' nor a zero byte, Slot is -1 or greater, and LeaveAt is
    after JoinAt when both are set. The error wraps ErrInvalidMember.

type Placement interface {
	// Rank returns the first min(n, p) members for key in namespace, best first, as a new
	// slice, where p is the number of members the placement places (an implementation that
	// gives several members one place documents it); nil when n <= 0 or p is 0. For a <= b,
	// Rank(namespace, key, a) is a prefix of Rank(namespace, key, b), so the first choice
	// never depends on n.
	Rank(namespace, key string, n int) []Member
}
    Placement places keys on one fixed list of members. Build one per member
    list, for example once per view, and reuse it for every lookup. A Placement
    is immutable and safe for concurrent use.

func NewRendezvous(members []Member) Placement
    NewRendezvous returns the Placement over members that ranks with Rank:
    its Rank method returns Rank(namespace, key, members, n). It copies members,
    so later changes to the slice do not affect it. NewRendezvous panics if two
    members share an ID.

type Term uint64
    Term numbers one acquisition of a shard. A store grants a new, larger term
    on every acquisition and never on renewal. Term 0 is never granted and means
    no term.

func NextTerm(prev Term, wall time.Time) Term
    NextTerm returns the term a store grants on an acquisition: the larger of
    prev+1 and wall in Unix milliseconds, where a time before 1970 counts as 0.
    prev is the shard record's previous term, or 0 when the store has no record.
    NextTerm panics if prev is the largest Term.

type Tick struct {
	// Now is the driver's monotonic reading.
	Now time.Duration
}
    Tick reports that time has passed and nothing else has happened.

type Timing struct {
	// LeaseDuration is how long another holder must observe a session unchanged before it
	// may take that session's shards.
	LeaseDuration time.Duration

	// RenewDeadline sets the session deadline: the send time of the last successful
	// renewal plus RenewDeadline.
	RenewDeadline time.Duration

	// RetryPeriod is the interval of session renewals and acquisition retries.
	RetryPeriod time.Duration

	// SlotGrace is how long a member must observe a slot vacant before the slot drops out
	// of the assignment, until it is claimed again.
	SlotGrace time.Duration
}
    Timing holds the session timings. Each member measures them on its own
    monotonic clock.

func (t Timing) DriftBound() float64
    DriftBound returns the clock-rate error t tolerates, (LeaseDuration -
    RenewDeadline) / (LeaseDuration + RenewDeadline), or 0 when that is negative
    or either duration is not positive. The owner stops before another holder
    may take over when every member's monotonic clock runs at a rate within 1 ±
    ρ for some ρ strictly below DriftBound, and no process pauses.

func (t Timing) Validate() error
    Validate reports whether t is usable: every field is positive and at most
    24 hours, RenewDeadline exceeds 1.2 times RetryPeriod (client-go's rule),
    LeaseDuration is at least 21/19 times RenewDeadline (a clock-rate tolerance
    of at least 5%), and SlotGrace is at least LeaseDuration. The error wraps
    ErrInvalidTiming.

type Tree struct {
	// Name is the key being split, and partition 0's key. It is non-empty and does not
	// end in "/" followed by a decimal number without leading zeros, so that keys of
	// different trees never collide.
	Name string

	// Read is the number of partitions readers poll: 0…Read-1. Read >= Write.
	Read int

	// Write is the number of partitions writers pick from: 0…Write-1. Write >= 1.
	Write int

	// Degree is the number of children per partition. Degree >= 1.
	Degree int
}
    Tree is the topology of one hot key split into partitions. Partition 0
    is the root and its key is Name, so a Tree with Read = Write = 1 behaves
    exactly like the unpartitioned key Name. Partition i > 0 has key Name + "/"
    + i and parent (i-1)/Degree, the formula Temporal's matching service uses
    for task queue partitions.

    Writers pick a partition in 0…Write-1 and readers poll 0…Read-1. To remove
    partitions, lower Write first, wait until every member uses the new value
    and the dropped partitions are empty, then lower Read. ValidateChange checks
    each step.

    A partition with no local match forwards its work to Parent(i); the root
    keeps it. What counts as a match is up to the caller.

func (t Tree) Children(i int) []int
    Children returns, in ascending order, the partitions in 0…Read-1 whose
    parent is i, or nil if there are none. It panics if i < 0 or Degree < 1.

func (t Tree) IsRoot(i int) bool
    IsRoot reports whether i is the root, partition 0. It panics if i < 0.

func (t Tree) Key(i int) string
    Key returns partition i's key: Name for the root and Name + "/" + i
    otherwise. It does not check i against Read, so a member with an older Tree
    value can still name a partition. Key panics if i < 0.

func (t Tree) Parent(i int) int
    Parent returns the partition that partition i forwards to, (i-1)/Degree.
    Parent(i) < i, so forwarding always reaches the root, and any range 0…P-1
    contains the parent of each of its partitions. Parent panics if i < 1 or
    Degree < 1.

func (t Tree) Pick(r uint64) int
    Pick returns the write partition for the random number r: r modulo Write.
    Callers pass a uniformly random r. Pick panics if Write < 1.

func (t Tree) PickRead(r uint64) int
    PickRead returns the read partition to poll for the random number r:
    r modulo Read. PickRead panics if Read < 1.

func (t Tree) Validate() error
    Validate reports whether t is usable: Name is non-empty and does not end
    in "/" followed by a decimal number without leading zeros, Write >= 1,
    Read >= Write and Degree >= 1. The error wraps ErrInvalidTree.

func (t Tree) ValidateChange(next Tree) error
    ValidateChange reports whether members may move from t to next:
    both are valid, the names are equal, and next.Read is at least t.Write,
    so no partition stops being polled while a member that has not yet applied
    next may still write to it. Partitions dropped from the read set must be
    empty before the change; ValidateChange cannot check that. The error wraps
    ErrInvalidTree.

type View struct {
	// Version increases with every new snapshot on the same member. core functions other
	// than the ownership machine ignore it.
	Version uint64

	// Members holds the members sorted by ID, with distinct IDs. Callers must not modify
	// it.
	Members []Member

	// Slots is the group's slot count; 0 means the group has no slots.
	Slots int

	// SlotHolders has one entry per slot: the holder string of the slot's holder, or ""
	// when the slot is vacant.
	SlotHolders []string
}
    View is a membership snapshot as one member sees it.

func (v View) Validate() error
    Validate reports whether v is well formed: every member is valid, members
    are sorted by ID with distinct IDs, Slots is not negative, SlotHolders has
    Slots entries, and in a view with slots every member's Slot is -1 or a held
    slot that no other member claims. The error wraps ErrInvalidView.

type ViewChanged struct {
	// Now is the driver's monotonic reading.
	Now time.Duration

	// View is the new snapshot.
	View View

	// Wall is the wall-clock time at Now.
	Wall time.Time
}
    ViewChanged delivers a new membership snapshot. The machine ignores a
    snapshot that is not valid or whose version is older than the last one it
    applied. A snapshot of the same version applies.

type Wake struct {
	// At is the reading, the one NextWake returns.
	At time.Duration
}
    Wake asks the driver to call Step again once its monotonic clock reaches a
    reading.
