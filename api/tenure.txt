package tenure // import "github.com/hmdsefi/tenure"

Package tenure shards single-writer services: each shard of a space has one
owner at a time, and every ownership carries a term that a downstream fence can
check.

CONSTANTS

const DefaultSlotGrace = 60 * time.Second
    DefaultSlotGrace is the SlotGrace that Start uses when
    Config.Timing sets other fields but leaves SlotGrace zero. It equals
    core.DefaultTiming.SlotGrace.


VARIABLES

var (
	// ErrNoSlot means the store has no free slot for the holder.
	ErrNoSlot = errors.New("tenure: no free slot")

	// ErrSessionLost means the holder's session has ended for good.
	ErrSessionLost = errors.New("tenure: session lost")

	// ErrClosed means the value has been closed, for example a Membership after Leave, and
	// takes no further calls.
	ErrClosed = errors.New("tenure: closed")

	// ErrNotOwner means this member does not own the shard. Every error of a Shard that is no
	// longer owned, and every *NotOwnerError, matches it with errors.Is.
	ErrNotOwner = errors.New("tenure: not owner")

	// ErrNoMembers means no member can serve the key, for example because no member of the
	// group is eligible.
	ErrNoMembers = errors.New("tenure: no members")

	// ErrDraining means the node is draining, or has drained, and refuses the call.
	ErrDraining = errors.New("tenure: draining")
)

TYPES

type Config struct {
	// Self is this member. Its ID must be valid as core.Member.Validate says, and no key of its
	// Meta may start with "tenure.", a prefix tenure reserves. Start ignores Slot and Draining:
	// the member always joins with Slot -1 and Draining false.
	Self Member

	// Membership tells the node which members its group has. It is required.
	Membership Membership

	// Store keeps the shard records, the session and, with slots, the slot records. It may be
	// nil only when Spaces is empty and Slots is 0: the node then only joins the group and
	// follows its views.
	Store Store

	// Slots is the slot count this member expects the group to have, or 0 for no slots. A count
	// above 0 needs a Store that is a SlotStore. Start writes the count when the store holds
	// none; when the store holds another count, the stored count wins.
	Slots int

	// Spaces lists the spaces whose shards this member takes part in.
	Spaces []Space

	// Timing holds the session timings. The zero value means core.DefaultTiming; otherwise a
	// zero SlotGrace means DefaultSlotGrace, so a LeaseDuration above DefaultSlotGrace needs
	// SlotGrace set.
	Timing core.Timing

	// Rand is the source of the 16 random bytes that name each session of this member. nil
	// means crypto/rand.Reader.
	Rand io.Reader

	// OnEvent, when not nil, is called with each event of the node, one at a time and in order.
	OnEvent func(Event)
}
    Config configures a node for Start.

    Write Config values with keyed fields: later versions add fields.

type Event struct{}
    Event is one thing that happened on a node, such as a change of the view,
    the session or a shard's ownership, as Config.OnEvent receives it. It has no
    fields yet.

type HeldError struct {
	// Holder is the holder the record names.
	Holder string

	// RetryAfter is how long the acquirer should wait before it tries again.
	RetryAfter time.Duration
}
    HeldError is the error Acquire returns when another holder has the shard.

func (e *HeldError) Error() string
    Error returns "tenure: held by <Holder>, retry after <RetryAfter>", with
    RetryAfter in time.Duration's String form.

type Holding struct {
	// Space and Shard name the shard.
	Space string
	Shard int

	// Holder is the holder the record names; "" means the record has no holder.
	Holder string

	// Term is the record's latest term. Clearing the holder keeps it.
	Term core.Term

	// Version orders the record's writes. Each write to a shard record, such as a grant, a clear
	// or a deletion, takes a version larger than that of every earlier write to any shard record
	// of the store. 0 means there is no record.
	Version uint64
}
    Holding is a shard record as a Store reports it.

type Member = core.Member
    Member is a member of a group, as core.Member describes it. The alias lets a
    program that uses tenure name members without importing core.

type Membership interface {
	// Join adds self to the group, or replaces the member with the same ID. It returns an error
	// that wraps core.ErrInvalidMember when self is not valid, and an error when the Membership
	// has joined already. The Membership keeps its own copy of self.Meta: no view shares the map
	// passed in.
	Join(ctx context.Context, self core.Member) error

	// Watch returns a channel that holds the current view and receives each later one. A view
	// lists the members sorted by ID. A new view, with the next Version, comes only when member
	// data changes: a change of Slot alone, or a Meta with the same content, makes none. The
	// channel holds one view, and a newer view replaces one not yet received. The channel is
	// closed when ctx is done and when Leave returns nil.
	Watch(ctx context.Context) (<-chan core.View, error)

	// SetDraining sets Draining of the member that joined. A draining member stays in the views.
	// Setting the value it already has makes no new view. It returns an error when the
	// Membership has not joined.
	SetDraining(ctx context.Context, draining bool) error

	// Leave removes the member that joined from the group, delivers the view without it, and
	// then closes every channel that Watch returned. Calling it before Join or again returns
	// nil.
	Leave(ctx context.Context) error
}
    Membership tells a member which members its group has. A member announces
    itself with Join, follows the group with Watch, marks itself as draining
    with SetDraining and leaves with Leave.

    Every method returns ctx.Err() itself when ctx is done, and then changes
    nothing. Once Leave has returned nil, Join, SetDraining and Watch return
    ErrClosed.

type NameChecker interface {
	// CheckNames returns an error when the backend cannot hold one of the space names, given in
	// Config.Spaces order and nil when there are none, or the member ID. A backend that keeps
	// no spaces ignores spaces.
	CheckNames(spaces []string, member string) error
}
    NameChecker is implemented by a Store or a Membership that cannot hold
    every name tenure accepts. Once the rest of the Config is valid, Start
    calls CheckNames before any other method of the store or the membership,
    and fails with an error that wraps the one CheckNames returns.

type Node struct {
	// Has unexported fields.
}
    Node is a running member of a group, as Start returns it. Its methods are
    safe for concurrent use.

    When the store reports the member's session lost, the node stops every
    shard it owns with a "lost" error, waits for every Run to return,
    and then goes on with a new incarnation: a new holder and a new session,
    under which it acquires its shards again. It stays in the group meanwhile,
    and keeps its watches.

func Start(ctx context.Context, cfg Config) (*Node, error)
    Start starts a node for cfg and returns it once the member has joined the
    group, the node holds a valid view of it and, with a Store, the member's
    session is open. It fails with an error that starts with "tenure: invalid
    config: " when cfg is not valid, and otherwise with the step that failed,
    such as "tenure: join: " and the error of Join, or "tenure: open session:
    " and the error of the store's KeepAlive. A failed Start closes the session
    again if it opened one, leaves the group again if it joined, and leaves no
    goroutine behind.

    ctx bounds Start only: Start's own calls of the membership and the store
    use it, and the node keeps running after ctx ends, until Close. Start does
    not wait for the shards of Spaces: the node acquires and runs them in the
    background, never under ctx.

func (n *Node) Close(ctx context.Context) error
    Close drains the node as Drain does, leaves the group, and stops every
    goroutine of the node. It returns nil once all of that is done. Later calls
    return ErrClosed, and so do Route, Local, Drain, SetSlots and the lookups
    of every Resolver the node returned; a Shard the node handed to Run keeps
    returning its stop error.

    When ctx ends before the drain completes, or is done already when Close is
    called, Close neither closes the member's session nor leaves the group:
    the store expires the session, so no other member takes one of the shards
    while a Run of this member may still act on it. A ctx done at the call does
    not start the drain at all. Close then stops every shard the member still
    owns, with a stop error ending in "closed", cancels the shard's Run with
    that error, stops the node and returns an error that wraps ctx's error
    and says what the drain had left, as Drain does, such as "tenure: close:
    context deadline exceeded (not released: orders/3)". It does not wait for
    a Run that has not returned: that Run's supervisor ends when it returns,
    and makes no call of its own then.

    No call of the membership or the store starts after Close has returned.
    Close waits for the calls in flight, whose context it cancels, so a call
    that does not return once its context is done holds Close up.

func (n *Node) Drain(ctx context.Context) error
    Drain hands the member's work over: it marks the member as draining in
    the group and, with a Store, stops the Run of every shard the member owns,
    releases each shard once its Run has returned, and closes the member's
    session. It returns nil once all of that is done. When the session is lost
    during the drain, there is nothing left to release or close: Drain returns
    nil once every Run has returned, and the node starts no new incarnation.
    The first call of Drain or Close starts the drain; later and concurrent
    calls wait for the same drain.

    When ctx ends first, Drain returns an error that wraps ctx's error and says
    what is left, and the drain goes on: a later Drain waits for it again. The
    error names the shards not released yet, those whose Run has not returned or
    whose release is still out, by space and then shard, as in "tenure: drain:
    context deadline exceeded (not released: orders/3, orders/5)". When every
    shard is released but the session is not closed yet, it ends in "(session
    not closed)".

    Drain returns ErrClosed after Close, during a Close whose ctx was done when
    it was called and that so skipped the drain, and when a Close stops the node
    before the drain completes.

func (n *Node) Local(space, key string) (*Shard, error)
    Local returns this member's Shard for key in space while the member owns it,
    that is while the Shard's Check returns nil. The shard of key is the one
    Route takes. Otherwise Local returns a *NotOwnerError for the shard, whose
    Route is the member Route names for key, or the zero Member when Route finds
    none. After Close, for an unknown space and for a ShardOf result outside
    the space's shards, Local fails as Route does. Local takes no lock and never
    waits for the node.

func (n *Node) Resolver(namespace string) *Resolver
    Resolver returns a Resolver that ranks keys in namespace over the node's
    views, the same views the node itself follows, with no watch of its own.
    It holds the node's current view at once, and places keys with
    core.NewRendezvous. Close of the node closes it; after Close, Resolver
    returns a closed Resolver, whose lookups return ErrClosed.

func (n *Node) Route(space, key string) (Member, error)
    Route returns the member that serves key in space: the member to which
    the node's latest view assigns key's shard. The shard is the space's
    ShardOf(key), or core.KeyShard(key, Shards) when ShardOf is nil. Route
    answers from the state the node has published and never waits for the node,
    so right after a view change it may still answer from the view before.
    The Meta map of the result is shared with the node's view and must not be
    modified.

    After Close, Route returns ErrClosed. It fails for a space the node does
    not have, such as `tenure: unknown space "carts"`, and for a ShardOf result
    outside the space's shards, such as `tenure: orders: ShardOf("k") = 9 is
    outside [0, 8)`. When no member can serve the shard, it returns an error
    that matches ErrNoMembers and names the shard, such as "tenure: no members:
    orders/3: no placement keys" when no member of the view is eligible.

    When the group has slots, shards are placed on slots: the member that
    serves a slot is the one whose ID is the ID part of the slot's holder,
    and the Slot of the result is that slot. A node routes the slot it holds to
    itself from the moment it has claimed it, before its view shows the claim.
    A vacant slot gives "tenure: no members: orders/3: slot-1 is vacant", and a
    holder whose member is not in the view gives "tenure: no members: orders/3:
    n4 is not in the view".

func (n *Node) SetSlots(ctx context.Context, count int) error
    SetSlots sets the slot count of the group, which the Store keeps, to count,
    and returns once this node follows it: once the node has read the slots
    again after the write and steps, and routes by, a view that holds what it
    read. Raising the count adds vacant slots, which standby members claim.
    Lowering it retires the highest slots: their holders hand their shards over
    to the members of the remaining slots and become standbys. SetSlots does not
    wait for that hand-over, and it does not need this member to hold a slot.
    A count of 0 turns slots off.

    SetSlots returns ErrClosed once Close has been called, and ErrDraining
    once Drain has been called. A negative count fails with "tenure: SetSlots:
    negative count -1", and a Store that does not implement SlotStore with
    "tenure: SetSlots: store does not implement SlotStore". Errors of the
    store's SetSlots, and of the read of the slots after it, start with "tenure:
    SetSlots: " and wrap the store's error. When ctx ends first, SetSlots
    returns an error that wraps ctx's error; the count may have been written by
    then.

    The wait goes on while the node steps no view, for example while it waits
    for a new session after losing one, until ctx ends or Close stops the node.
    When Close stops the node first, SetSlots returns ErrClosed.

type NotOwnerError struct {
	// Space and Shard name the shard.
	Space string
	Shard int

	// Route is the member that serves the shard, or the zero Member when none is known.
	Route Member
}
    NotOwnerError reports that this member does not own a shard, and names the
    member a request for the shard should go to instead.

func (e *NotOwnerError) Error() string
    Error returns text such as "tenure: not owner of orders/3: route to n2
    (10.0.0.7:8080)". The address is left out when Route has none, and the text
    ends in "no route" when Route has no ID.

func (e *NotOwnerError) Is(target error) bool
    Is reports whether target is ErrNotOwner, so that errors.Is(err,
    ErrNotOwner) holds for a *NotOwnerError.

type PropagationEstimator interface {
	// Propagation returns how long a change of one member takes to appear in the views of every
	// member; 0 means at once.
	Propagation() time.Duration
}
    PropagationEstimator is implemented by a Membership that can tell how long a
    change takes to reach every member.

type Resolver struct {
	// Has unexported fields.
}
    Resolver places keys on the members of a group, by rendezvous rank unless
    WithPlacement says otherwise, with no leases: any number of keys, each
    served by the members ranked first for it. It ranks the eligible members of
    the latest view, as core.Eligible gives them at the current wall-clock time:
    members that are not draining, inside their JoinAt and LeaveAt window,
    and not standbys. It builds one core.Placement for each new list of eligible
    members and keeps it until that list changes; when a member's JoinAt or
    LeaveAt comes, it updates the list at that instant.

    NewResolver returns a Resolver that follows a Membership itself;
    Node.Resolver returns one that follows the node's views. A Resolver's
    methods are safe for concurrent use. Lookup, LookupN and Members never wait
    for a view or for another call.

func NewResolver(m Membership, opts ...ResolverOption) (*Resolver, error)
    NewResolver returns a Resolver that follows the views of m. It calls m.Watch
    once and returns its error, as "tenure: NewResolver: watch: " and the error,
    but never calls Join: m serves only to watch the group, and the Resolver
    ranks whatever members its views hold. NewResolver does not wait for the
    first view; until it comes, Lookup returns ErrNoMembers.

    When the channel of Watch closes, or a later Watch fails, the Resolver calls
    Watch again core.DefaultTiming.RetryPeriod later, until Close or until Watch
    returns ErrClosed; after ErrClosed it keeps its last list. Views that are
    not valid are ignored.

func (r *Resolver) Close() error
    Close stops the Resolver: lookups return ErrClosed, every channel of
    Subscribe is closed, and every goroutine of the Resolver has returned when
    Close returns. Later calls return ErrClosed, also only once those goroutines
    have returned.

func (r *Resolver) Lookup(key string) (Member, error)
    Lookup returns the member ranked first for key. It returns ErrNoMembers when
    no member is eligible, and ErrClosed after Close.

func (r *Resolver) LookupN(key string, n int) ([]Member, error)
    LookupN returns the first n members for key, best first, as a new slice:
    all the eligible members when fewer than n are. The first member is the one
    Lookup returns, and for a <= b, LookupN(key, a) is a prefix of LookupN(key,
    b). It returns ErrClosed after Close, an error when n is below 1, and
    ErrNoMembers when no member is eligible.

func (r *Resolver) Members() []Member
    Members returns the eligible members in ID order, as a new slice; nil when
    none is eligible, before the first view and after Close.

func (r *Resolver) Subscribe() <-chan []Member
    Subscribe returns a channel that receives the list of eligible members,
    as Members returns it, each time the list changes. It holds the current
    list at once when a view has come. The channel holds one list, and a newer
    list replaces one not yet received, so a slow receiver gets the latest.
    Close closes the channel; after Close, Subscribe returns a closed channel.

type ResolverOption func(*resolverOptions)
    A ResolverOption changes how NewResolver builds a Resolver.

func WithNamespace(namespace string) ResolverOption
    WithNamespace makes the Resolver rank keys in namespace, so that the same
    key in different namespaces lands on different members. The default is "".

func WithPlacement(place func(members []Member) core.Placement) ResolverOption
    WithPlacement makes the Resolver build its placements with place instead
    of core.NewRendezvous. The Resolver calls place once for each new non-empty
    list of eligible members, in ID order, and asks the returned Placement,
    which must not be nil, for every lookup until the list changes. A nil place
    keeps the default.

type Shard struct {
	// Space is the name of the shard's space.
	Space string

	// ID is the shard's number in its space, from 0 to the space's Shards minus 1.
	ID int

	// Term is the term of this ownership. It grows with every acquisition of the shard, so a
	// downstream fence that keeps the highest term seen rejects the writes of an older owner.
	Term core.Term

	// Has unexported fields.
}
    Shard is one ownership of a shard by this member: the node hands it to a
    space's Run when the member takes the shard, and Run checks it before every
    side effect. A Shard stays valid until the member stops owning the shard
    under its Term; a later ownership of the same shard gets a new Shard.

    A Shard is safe for concurrent use, and a copy of a Shard checks the same
    ownership. A Shard that the node did not make, such as the zero Shard,
    is never owned.

func (s *Shard) Check() error
    Check returns nil while this member owns the shard. Otherwise it returns
    an error that matches ErrNotOwner and says why, for example "tenure:
    not owner of orders/3 (term 42): moved". Once the shard has stopped, every
    call returns the same error, which is also the cause of Run's context. In a
    space without fencing the shard is owned only until the session deadline:
    from that instant Check returns an error ending in "expired", even before
    the node stops the shard. A Shard the node did not make returns ErrNotOwner.
    Check does not allocate.

func (s *Shard) Valid() bool
    Valid reports whether this member owns the shard: it is Check() == nil.
    Valid does not allocate.

type SlotStore interface {
	// ClaimSlot returns the lowest slot that holder holds below the count, without writing. When
	// holder holds no slot below the count but one at or above it, or no slot below the count is
	// free, it returns -1 and ErrNoSlot. Otherwise it claims the lowest free slot: one with no
	// record, no holder, or a holder whose session is not live. ClaimSlot needs the live session
	// of holder; otherwise it returns ErrSessionLost.
	ClaimSlot(ctx context.Context, holder string) (int, error)

	// ReleaseSlot clears the slot's holder when the slot record names holder. Any other record,
	// or none, is left as it is, and ReleaseSlot still returns nil. It does not look at the
	// session of holder.
	ReleaseSlot(ctx context.Context, holder string, slot int) error

	// Slots returns the slot count and one entry per slot below it: the holder of the slot while
	// its session is live, else "". When the count is 0 it returns 0, nil, nil.
	Slots(ctx context.Context) (count int, holders []string, err error)

	// SetSlots sets the slot count. It changes no slot record, so the holder of a slot at or above
	// the new count keeps it until the slot is released or the holder's session is closed.
	SetSlots(ctx context.Context, count int) error
}
    SlotStore is implemented by a Store that keeps slots. A slot record names
    the holder of one slot; the holder counts only while its session is live.
    The slot count belongs to the whole group.

type Space struct {
	// Name identifies the space in the store and in routing. It is non-empty, contains neither
	// "/" nor a zero byte, differs from the Name of every other space of the Config, and is none
	// of the names tenure reserves: "generation", "member", "slot", "slots" and "request".
	Name string

	// Shards is the number of shards in the space, at least 1.
	Shards int

	// Fenced reports that a downstream fence checks the term of every write to the space's
	// state. A fenced shard's Run keeps going, degraded, while the session is not live; an
	// unfenced shard stops at the session deadline.
	Fenced bool

	// Run serves one shard while this member owns it. The node calls it with the shard's
	// Shard and cancels ctx when the ownership ends. When Run returns while the member still
	// owns the shard, the node calls it again after a backoff. It is required.
	Run func(ctx context.Context, s *Shard) error

	// ShardOf maps a key to its shard for Node.Route and Node.Local. It must return a shard
	// from 0 to Shards minus 1, the same one for the same key on every member, and be safe for
	// concurrent use; Route and Local fail for a key it maps outside. Route and Local call it
	// on their caller's goroutine, so a panic in it reaches that caller and leaves the node
	// running. nil means core.KeyShard(key, Shards).
	ShardOf func(key string) int
}
    Space is a set of shards that the members of a group divide among
    themselves.

    Write Space values with keyed fields: later versions add fields.

type Store interface {
	// KeepAlive opens a session for a holder that has never had one, or renews the live session
	// of holder and stores timing as its new Timing. It returns ErrSessionLost when the session
	// of holder has ended, also when the renewal arrives at or after its expiry, and when
	// CloseSession named holder before it ever had a session. A renewal never grants a term.
	KeepAlive(ctx context.Context, holder string, timing core.Timing) error

	// Acquire grants the shard to holder and returns the new term, when the record is absent,
	// has no holder, names a holder whose session is not live, or names holder itself. The new
	// term is core.NextTerm of the record's term (0 when there is no record) and the current wall
	// time, so it is larger than every earlier term of the shard unless the store lost the
	// record. Otherwise Acquire returns 0 and a *HeldError that names the record's holder, with
	// the RetryPeriod of holder's own Timing as RetryAfter. A grant is atomic with the read it
	// rests on, so of racing calls by different holders at most one is granted a term. Acquire
	// needs the live session of holder; otherwise it returns ErrSessionLost.
	Acquire(ctx context.Context, holder, space string, shard int) (core.Term, error)

	// Release clears the record's holder when the record names holder at term, and keeps the
	// term. Any other record, or none, is left as it is, and Release still returns nil. It does
	// not look at the session of holder.
	Release(ctx context.Context, holder, space string, shard int, term core.Term) error

	// Confirm returns the shard's record, which shows every write committed before the call and
	// every grant to another holder that did not see the latest successful renewal of holder: no
	// such grant commits after Confirm returns. A store that decides expiry on its own clock gets
	// this from a read; one that lets acquirers decide it may need a write, which makes such a
	// grant still in flight fail. Either way Confirm changes neither the holder nor the term of
	// the record. An absent record reads as Holding{Space: space, Shard: shard}. term is the term
	// the caller holds the shard at; Confirm does not compare it with the record. Confirm needs
	// the live session of holder; otherwise it returns ErrSessionLost.
	Confirm(ctx context.Context, holder, space string, shard int, term core.Term) (Holding, error)

	// CloseSession ends the session of holder for good, also for a holder that is unknown or
	// already ended, and clears the holder of every shard record and slot record that names it,
	// keeping the terms. It never returns ErrSessionLost.
	CloseSession(ctx context.Context, holder string) error

	// Holdings returns every record of space, also those with no holder, sorted by shard. It does
	// not look at sessions: Holder is the holder a record names, whether or not its session is
	// live. The slice is the caller's own.
	Holdings(ctx context.Context, space string) ([]Holding, error)
}
    Store keeps the shard records of every space and the sessions of their
    holders. A record names the holder of one shard, or no holder, and the
    shard's latest term. A Store is safe for concurrent use, also when several
    clients share one backend.

    A holder string names one session. Its member ID is the text before the
    first "/", or the whole string when it has none. A session is live from
    its first successful KeepAlive until it ends for good: when it expires,
    LeaseDuration of its own Timing after its last renewal; when a session of
    the same member ID opens; or when CloseSession names it. An ended session's
    records stay as they are, and any live holder may take them at once.

    The store decides expiry on a clock of its own, or lets the acquirer decide
    it: then an acquirer may take a record once it has observed the holder's
    session unchanged for that LeaseDuration on its own monotonic clock.
    A renewal that lands while such a takeover is in flight can keep the session
    live although the shard is taken; Confirm shows such a takeover.

    Every method here and in SlotStore and Watcher returns ctx.Err() itself,
    and changes nothing, when ctx is already done at the call. It then checks
    its arguments in parameter order, with errors of the store's own; then,
    if it needs the live session of holder, returns ErrSessionLost when that
    session is not live; and only then returns a *HeldError or ErrNoSlot.
    The argument checks reject at least an empty holder or space, a holder or
    space that contains a zero byte, a space that contains "/", a negative shard
    or slot, a term of 0 and a negative slot count; a store may reject more,
    such as names its backend cannot hold. A call that fails an argument check,
    or returns ErrSessionLost, a *HeldError or ErrNoSlot, changes nothing.
    Any other error, such as a failed request or a context that ends during the
    call, leaves the outcome unknown: the call may have taken effect.

type TimingChecker interface {
	// CheckTiming returns an error when the backend cannot work with t, the timing the node
	// will use, its defaults applied.
	CheckTiming(t core.Timing) error
}
    TimingChecker is implemented by a Store or a Membership that cannot work
    with every valid Timing. Start calls CheckTiming after CheckNames and before
    any other method of the store or the membership, and fails with an error
    that wraps the one CheckTiming returns.

type Watcher interface {
	// WatchHolders returns a channel that receives, in commit order, every write to a shard record
	// of any space committed after WatchHolders returns, each as the record after the write. A
	// deletion arrives as a Holding with only Space, Shard and Version set, Version being the
	// deletion's. When the store cannot deliver every such write, it closes the channel instead.
	// The channel is closed once ctx is done.
	WatchHolders(ctx context.Context) (<-chan Holding, error)
}
    Watcher is implemented by a Store that reports changes to its shard records.
